# 社区协作

问题与需求提交到 g2rain [Issues](https://github.com/g2rain/g2rain/issues)，开放讨论使用 [Discussions](https://github.com/g2rain/g2rain/discussions)。安全问题按仓库安全策略私下报告。

提交变更时列出受影响的公共 API、消费方兼容性、测试结果和发布影响。跨项目公共库规范成熟后，应提议中央 `java-library` Profile，而不是把 `java-domain-service` 规则复制到本项目。
